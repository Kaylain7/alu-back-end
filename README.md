# ALU Back-End: API

This project uses Python scripts to interact with a REST API and export employee TODO data to CSV and JSON formats.

## Files

- `api/0-gather_data_from_an_API.py` - Display employee TODO progress
- `api/1-export_to_CSV.py` - Export tasks to CSV
- `api/2-export_to_JSON.py` - Export tasks to JSON
- `api/3-dictionary_of_list_of_dictionaries.py` - Export all employees to JSON

## Usage

```bash
python3 0-gather_data_from_an_API.py <employee_id>
```
